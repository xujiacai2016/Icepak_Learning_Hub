# Icepak Interactive Learning Platform V2.0 重构总览

## 1. 项目定位

**当前项目：** Icepak Learning Hub  
**V2.0定位：** 基于 `Ansys_Icepak_Users_Guide` 及其图片构建的 Icepak 可视化学习与操作训练平台。

V2.0 不以“展示文档”为主要目标，而是建立以下完整学习闭环：

```text
Guide内容 → 软件截图 → 选项定位 → 作用说明 → 参数关系
→ 组合效果 → 操作练习 → 错误反馈 → 测验验证
```

## 2. 核心用户需求

1. 在网页中查看 Icepak 操作界面和选项位置。
2. 理解每个选项的作用、可选值和前置条件。
3. 区分软件默认值、Guide示例值、推荐值和待验证建议。
4. 理解选项与其他选项的依赖、影响和组合关系。
5. 通过点击、排序、配对、诊断等交互方式练习操作。
6. 从工作流和案例中掌握完整仿真过程。
7. 所有知识可追溯到章节、页码、图号或内部案例。

## 3. 设计原则

- **不推倒重来：** 最大限度复用现有页面、组件、JSON和图片资产。
- **先数据后页面：** 先统一数据模型，再重构展示和交互。
- **图片与内容直接关联：** 图片放在对应选项、步骤或案例中，不建立脱离语境的图片图库。
- **来源可追溯：** 每条官方知识记录文档、版本、章节、页码和图号。
- **证据分级：** Official、Default、Tutorial、Practice、Verify 分开显示。
- **禁止编造：** 无Guide依据或案例验证的内容不得显示为官方推荐。
- **垂直切片优先：** 先完整交付 Fans Panel，再扩展 Mesh、Radiation、Transient。
- **Git保护：** 所有V2.0改动在独立分支完成，不批量删除现有文件。

## 5. 内容来源边界

### 官方来源
- Ansys Icepak User's Guide
- Ansys Icepak Tutorials

### 内部来源
- EDFA、RAMAN、Line Card、OCM、OTDR等实际项目经验
- 内部DFM及热设计案例

### 必须区分

| 标签 | 含义 |
|---|---|
| Official | Guide明确说明 |
| Default | 软件默认设置 |
| Tutorial | Guide或Tutorial示例设置 |
| Practice | 内部工程实践 |
| Verify | 尚需验证的建议 |

