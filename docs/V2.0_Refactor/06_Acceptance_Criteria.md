# Icepak Interactive Learning Platform V2.0 验收标准

## 1. 单个选项完成标准

一个Option只有满足以下条件才可标记为 `reviewed` 或 `verified`：

- [ ] 唯一ID
- [ ] 英文名称和中文名称
- [ ] 所属Panel和Tab
- [ ] 在图片中可定位
- [ ] 用途说明
- [ ] 可选值说明
- [ ] 默认值与示例值分开
- [ ] 推荐值有依据，否则为空
- [ ] 前置条件
- [ ] 至少一条相关关系或明确标记暂无
- [ ] 影响说明或明确标记待验证
- [ ] 风险或常见错误
- [ ] 验证方法
- [ ] SourceReference
- [ ] EvidenceLevel
- [ ] Review状态

## 2. 图片完成标准

- [ ] 相对路径有效
- [ ] 图片可加载
- [ ] 章节、页码、图号完整
- [ ] 图名完整
- [ ] 使用范围记录
- [ ] 版权/内部使用说明记录
- [ ] 热点坐标合规
- [ ] 桌面端热点准确
- [ ] 移动端热点准确
- [ ] 图片与对应内容直接关联

## 3. 关系完成标准

- [ ] fromId存在
- [ ] toId存在
- [ ] 关系类型有效
- [ ] 方向明确
- [ ] 条件明确
- [ ] 说明不夸大
- [ ] 有来源或标记Verify
- [ ] 可从两端导航

## 4. 组合完成标准

- [ ] 组合场景明确
- [ ] 每个选项状态明确
- [ ] 前置条件明确
- [ ] 预期效果不编造
- [ ] 风险明确
- [ ] 验证方法明确
- [ ] Official / Tutorial / Practice / Verify标记正确
- [ ] 不将单一Guide示例泛化为普遍推荐

## 5. Workflow完成标准

- [ ] 学习目标明确
- [ ] 步骤顺序正确
- [ ] 每步绑定Panel/Option/Image
- [ ] 前置条件明确
- [ ] 操作说明清晰
- [ ] 常见错误明确
- [ ] 完成标准可判断
- [ ] 来源可追溯
- [ ] 至少一种练习可用

## 6. Practice完成标准

- [ ] 任务目标明确
- [ ] 初始状态明确
- [ ] 用户操作可记录
- [ ] 正误判断规则明确
- [ ] 反馈解释充分
- [ ] 失败后可重试
- [ ] 答案不直接暴露
- [ ] 来源或证据等级完整

## 7. 页面验收

- [ ] 首次加载无控制台错误
- [ ] 导航可用
- [ ] 数据缺失时显示友好提示
- [ ] 不因空数组崩溃
- [ ] 键盘可访问
- [ ] 图片有替代文本
- [ ] 桌面和移动端布局可用
- [ ] 不暴露本地路径、API Key或敏感信息
- [ ] V1核心页面仍可访问

## 8. 内容治理验收

- [ ] Guide内容可追溯
- [ ] Guide示例与内部建议分开
- [ ] 默认值不等于推荐值
- [ ] 没有未经核实的参数推荐
- [ ] 内部案例与公开内容可分离
- [ ] 原始Guide不被网站公开下载
- [ ] 图片使用符合适用许可和内部政策

## 9. Git验收

- [ ] 在 `v2-refactor` 分支开发
- [ ] 提交信息清晰
- [ ] 每个提交范围可审阅
- [ ] 没有大规模无关格式化
- [ ] 没有删除未迁移资产
- [ ] 可恢复到V1.0基线

## 10. V2.0 MVP完成定义

MVP至少包含：

```text
1个完整Panel
2张带来源的界面图片
6个以上可学习Option
OptionValue比较
3条以上关系
1个Tutorial组合
1个Workflow
2种Practice
3道以上Quiz
完整来源展示
```

建议首个MVP采用Fans Panel垂直切片。
