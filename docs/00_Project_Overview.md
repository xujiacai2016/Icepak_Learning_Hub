# Icepak Learning Hub Project Overview

Version: V1.0

Project: Icepak Learning Hub

Author: Xu, Jia Cai

Date: 2026-08-19

---

## 1. 项目定位

Icepak Learning Hub 是一个面向机械结构设计工程师、热设计工程师和仿真工程师的交互式学习平台。

项目目标不是简单复制 Icepak User Guide，而是建立一个能够帮助用户理解 Icepak 设置背后物理逻辑、工程逻辑和故障诊断逻辑的学习系统。

---

## 2. 核心问题

本项目围绕三个第一性原理问题展开：

```text
热从哪里来？
热经过哪里？
热如何离开？
```

对应 Icepak 仿真主链路：

```text
Geometry
↓
Material
↓
Power
↓
Boundary
↓
Flow
↓
Thermal
↓
Mesh
↓
Solver
↓
Post
↓
Design Decision
```

---

## 3. 项目目标

建立以下知识与学习模块：

- Workflow Map
- Logic Tree
- Glossary
- Troubleshooting Tree
- Quiz System
- Case Library
- UI Information Architecture
- Project File Structure
